## Prerequisites

Before you begin, make sure you have:

- **Node.js 18+** — [Download](https://nodejs.org)
- **PostgreSQL 14+** — local or hosted
- **Git**

<Tip>
  Want to skip setup? Use the [Live Demo](/demo) to explore Pryrox instantly with a pre-loaded test pharmacy — no installation required.
</Tip>

## 1. Clone the repository

```bash
git clone https://github.com/pryrolab-eng/pryro-phramacy.git
cd pryro-phramacy
```

## 2. Set up the backend

```bash
cd backend
npm install
cp .env.example .env
```

Edit `.env` with your PostgreSQL connection string and other required values. See [Environment Variables](/installation/environment-variables) for the full reference.

```bash
npx prisma migrate deploy
npx prisma generate
npm run build
npm run start:prod
```

The API will be available at `http://localhost:3000`.

## 3. Set up the frontend

```bash
cd ../frontend
npm install
cp .env.example .env
npm run build
npm run start
```

The app will be available at `http://localhost:3001`.

## 4. Create your first pharmacy

1. Open `http://localhost:3001` in your browser
2. Sign up for a new account
3. Complete the onboarding to create your pharmacy
4. Go to **Settings → EBM / VSDC** to configure your RRA TIN and VSDC connection

## 5. Open the POS

1. Go to **POS** in the sidebar
2. Open a cashier shift
3. Add items to the cart and complete a test sale

<Check>
  If the sale completes and shows a receipt with an SDC Information block, your EBM integration is working correctly.
</Check>
