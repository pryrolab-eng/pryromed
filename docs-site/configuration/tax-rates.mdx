---
title: Tax Rates
description: Assigning RRA tax classes to medications
---

Each medication must have a tax class assigned. Go to **Inventory → Medications → Edit** and select the Tax Class.

| Class | Rate | Use for |
|-------|------|---------|
| **A** | 0% | Tax-exempt items |
| **B** | 18% | Standard pharmaceutical products |
| **C** | 0% | Zero-rated items |
| **D** | 0% | Other zero-rated |

If no class is assigned, Pryrox defaults to **B** and logs a warning. See [Tax Computation](/ebm/tax-computation) for the VAT formula.
