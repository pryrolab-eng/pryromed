title: Configuration Overview
description: Configure Pryrox for your pharmacy
---

<Steps>
  <Step title="Pharmacy profile">Set TIN, name, address in **Settings → Pharmacy Profile**</Step>
  <Step title="Tax rates">Assign Tax Class A/B/C/D to each medication</Step>
  <Step title="VSDC connection">Enter VSDC URL, branch ID, device serial in **Settings → EBM**</Step>
  <Step title="Device initialization">Click Save — initialization triggers automatically</Step>
  <Step title="Item sync">Sync medication catalogue to VSDC</Step>
  <Step title="Verify">Process a test sale and confirm the SDC block appears on the receipt</Step>
</Steps>
