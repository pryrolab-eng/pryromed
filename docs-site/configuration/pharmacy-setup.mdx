---
title: Pharmacy Setup
description: Configure your pharmacy profile and TIN
---

Go to **Settings → Pharmacy Profile** and fill in:

| Field | Notes |
|-------|-------|
| **Pharmacy Name** | Must exactly match your RRA-registered name |
| **TIN** | 9-digit Tax Identification Number |
| **Address** | At least 3 lines (required for receipt header) |
| **Phone** | Printed on receipts |

Save. The TIN is used for all VSDC API calls.
