## Demo limitations

- The EBM integration in demo mode connects to the **RRA test VSDC** — fiscal receipts are test receipts only
- Sales and inventory changes reset every 24 hours
- Email notifications are disabled in demo mode
- You cannot add real staff accounts or change company TIN in demo mode

## Test mode for developers

If you are integrating Pryrox with your own systems, you can use the API in test mode:

```bash
# All API calls with this header use test/sandbox data
X-Pryrox-Mode: test
```

The test mode:
- Uses a separate test database scoped to your test TIN
- Connects to the RRA test VSDC server
- Does not affect production data
- Resets on demand via `POST /api/test/reset`

See the [API Reference](/api-reference/overview) for test mode details.
