<Info>
  The **Document Reference** column below shows exactly what to write in the RRA Excel form.
  All references point to sections of the submitted **Pryrox CIS Technical Specification (PRYROX-CIS-TECH-SPEC-v1.0)**.
</Info>

## How to fill the RRA Excel

For the **Document Reference** column in the RRA form, write the section reference like this:

> `Technical Specification §4.2 — QR Code Format`

RRA evaluators will open the submitted Technical Specification PDF, go to that section, and verify the claim. They do **not** check source code.
