## Base URL

```
https://your-pryrox-server/api
```

For local development: `http://localhost:3000/api`

## Authentication

All endpoints require a valid session cookie (`pryrox_session`). Obtain it by signing in at `/api/auth/signin`.

For server-to-server requests, use an API key:

```bash
Authorization: Bearer your-api-key
```

## Test mode

Add this header to any request to use the test/sandbox environment:

```bash
X-Pryrox-Mode: test
```

In test mode:
- Requests use a sandboxed test pharmacy
- EBM submissions go to the RRA test VSDC server
- No production data is affected
- Reset test data: `POST /api/test/reset`

## Response format

All responses return JSON. Successful responses use `2xx` status codes.

```json
{
  "success": true,
  "data": { ... }
}
```

Error responses:
```json
{
  "error": "Description of what went wrong",
  "code": "ERROR_CODE"
}
```

## Rate limiting

- Default: **100 requests per minute** per IP
- EBM endpoints: **60 requests per minute** per pharmacy
