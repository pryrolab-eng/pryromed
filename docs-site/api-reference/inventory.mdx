---
title: Inventory API
description: Inventory and medication endpoints
---

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/inventory` | List inventory rows |
| POST | `/api/inventory` | Add medication/inventory batch |
| PUT | `/api/inventory/:id` | Update inventory item |
| DELETE | `/api/inventory/:id` | Remove inventory item |
| GET | `/api/inventory/stock-alerts` | Low-stock and near-expiry alerts |
| GET | `/api/inventory/analytics` | Stock value and category breakdown |
| POST | `/api/inventory/transfer` | Transfer stock between branches |
| POST | `/api/inventory/import` | Bulk import from CSV/Excel |
