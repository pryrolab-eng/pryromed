---
title: Reports API
description: Reporting endpoints
---

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/reports/sales` | Sales report aggregates |
| GET | `/api/reports/financial` | Financial performance report |
| GET | `/api/reports/tax` | VAT and tax transaction report |
| GET | `/api/reports/plu` | PLU report — quantities sold and remaining stock |
| GET | `/api/reports/detailed?type=sales\|purchases\|stock\|items\|importation` | Detailed report by type |
| GET | `/api/reports/insurance-claims` | Monthly insurance claims report |
| GET | `/api/reports/combined` | Combined dashboard data |
| GET | `/api/reports/audit` | Pharmacy audit log entries |
