---
title: Cashier POS Guide
description: How to use the Pryrox Point of Sale screen
---

The POS screen is your main sales interface. It is divided into three panels:

1. **Product search** — search by name, barcode, or category
2. **Cart** — items added for the current sale
3. **Payment** — select method and complete the sale

## Keyboard shortcuts

| Action | Shortcut |
|--------|----------|
| Focus search | `/` |
| Clear cart | `Escape` |
| Complete sale | `Enter` (when cart is not empty) |

## Barcode scanning

Connect a USB barcode scanner. It inputs directly into the search field. Press Enter or wait for automatic add when a single match is found.

## FEFO batch selection

Pryrox automatically selects the **First Expiry, First Out** batch. The expiry date is shown on each cart line. If a batch is within 30 days of expiry, a yellow warning appears — confirm to continue.
